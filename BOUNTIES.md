# Bounty Program

To help new contributors get started, a subset of `good first issue` items carry a
small bounty, paid through [Algora](https://algora.io) (or a similar platform).

## How it works

1. **Find a bounty** — browse issues labelled
   [`bounty`](https://github.com/dark-princezz/stellar-hooks/issues?q=is%3Aissue+is%3Aopen+label%3Abounty).
   The amount is shown in the issue body / Algora comment.
2. **Claim it** — comment `/attempt #<issue-number>` (Algora) or leave a comment asking to be assigned.
   One active bounty per contributor at a time.
3. **Open a PR** — follow [CONTRIBUTING.md](CONTRIBUTING.md) and include `/claim #<issue-number>` in the PR description.
4. **Get paid** — once a maintainer merges the PR, the bounty is released.

## Rules

- Bounties are only paid for **merged** PRs that meet the issue's acceptance criteria.
- If there is no activity on an assigned bounty for **7 days**, it may be reassigned.
- Low-effort, AI-spam, or duplicated PRs will be closed without payment.
- Maintainers have the final say on scope and payout.

## For maintainers

- Only tag well-scoped `good first issue` items with `bounty`.
- Add the bounty via Algora: comment `/bounty $<amount>` on the issue.
- Keep amounts small (e.g. $10–$50) and state the acceptance criteria clearly.
